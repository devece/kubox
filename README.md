# Kubox - Sistema de Administración de Edificios

## Descripción
Sistema completo para la gestión de condominios y edificios.

## Tecnologías
- **Backend**: Node.js + Express + SQLite3
- **Frontend**: React + Vite + TailwindCSS
- **Autenticación**: bcrypt

## Instalación

### Backend
```bash
cd backend
npm install
node index.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
